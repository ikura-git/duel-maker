# duelcard-maker
このアプリはデュエルマスターズのカードを生成するアプリです。
* ファイルをインポートし、画像欄への追加
* カードタイプの選択
* カード名、種族、パワー等の選択
* 文明の選択(多色化)
* 主なキーワード能力の指定
* カード効果の記入
等をしたのちに保存ボタンを押すとpng形式で保存することができます。

以下のデプロイでも一応動作しますが、
自身でダウンロードしてindex.htmlを開くほうが安定して動作すると思います。
